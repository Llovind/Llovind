## 👋 About Me

I'm a Telecommunication Engineering student focused on **network defense, security operations, and cloud infrastructure**. I'd rather ship a working detection pipeline than just read about one.

- 🛡️ Building **Human Firewall Lite** — a closed-loop phishing simulation & crowdsourced threat reporting platform (GoPhish + Flask + n8n + Telegram Bot)
- 🤖 Deployed a Transformer-based intrusion detection model (**92.69% recall, 97.42% ROC-AUC**) as part of an AI-assisted SOC pipeline, validated on live SSH brute-force traffic
- 🔬 Researching SDN-based Intrusion Prevention Systems and Cache Pollution Attack mitigation for Named Data Networking (IEEE submission track)
- 📊 Building an end-to-end **KPI analytics platform** for fiber & telecommunications operations — ETL pipelines and ML models (forecasting, clustering, anomaly detection) over real operational data
- 📈 Also lead Human Capital work for a research lab, designing KPI evaluation frameworks — turns out organizing people is its own kind of system design
- 🌱 Currently deepening AWS Cloud and Microsoft SC-500
- 💬 Ask me about: SOC pipelines, SDN/NDN, phishing simulation architecture, or why "least privilege" should be everyone's default answer
